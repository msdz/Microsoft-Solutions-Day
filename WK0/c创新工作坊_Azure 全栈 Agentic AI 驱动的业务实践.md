# 创新工作坊：Azure 全栈 Agentic AI 驱动的业务实践

## 介绍

上午，我们共同探讨了企业如何从智能体构建探索业务价值实现路径。下午的Azure工作坊将进一步把这一理念转化为实践——它不是一场产品培训，而是一场 Agent Native 工作方式 的沉浸式体验。
通过真实零售业务场景，借助智能 GitHub Copilot 副驾驶® 、Fabric IQ、 Foundry IQ 与 AKS能力，学员将以“Agent 驱动工作”的全新方式，完成零售业务 Agent 的部署与应用实践，并体验 Agent 如何实现数据分析与业务洞察，同时深入了解 Agent 背后如何连接企业数据、模型与云平台能力。 
这不仅是一次简单的AI技术实践，而是从通过Azure全栈技术能力构建 Agent，到驾驭 Agent，再到探索业务价值实践，更是一次思路的拓展和全新工作方式的体验。
