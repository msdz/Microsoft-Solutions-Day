# 实验 03：识别智能体增量价值与构建路径

## 实验目标

上一实验已经验证，智能 Microsoft 365 Copilot 副驾驶®能够帮助 Amanda 理解资料、分析关联并生成工作成果。本实验将进一步识别可复用的工作方式，并为第一个业务智能体确定清晰、适度的原型范围。

完成本实验后，您将能够：

- 从现有成果中识别智能体的增量价值
- 区分知识复用、工作委托、业务连接和可信治理机会
- 根据业务目标选择合适的体验或构建方式
- 完成一张“智能体机会与路径卡”
- 为 Agent Builder 原型准备角色、目标、知识、输出和人工确认点

## 场景背景

Amanda 已经形成项目状态摘要、风险关联分析和管理层评审草稿。团队希望把其中稳定、重复且可验证的工作方式复用起来，同时继续由授权人员负责上市审批、风险关闭和对外发布。

本实验不以“寻找产品不足”为目标，而是回答：**哪些工作环节能够从按需协助进一步发展为可复用、可委托、可连接且可信的工作方式？**

## Exercise 2：识别四类增量价值

### Step 1：分类机会

| 机会类型 | 说明 | Launch Readiness 示例 |
|---|---|---|
| 知识复用机会 | 将规则、术语、模板和团队经验形成一致的知识基础 | 统一风险口径与评审结构 |
| 工作委托机会 | 将多个相关步骤作为一个完整目标进行委托 | 准备完整的 Launch Readiness Review |
| 业务连接机会 | 根据场景连接数据、工具、流程和渠道 | 创建 Planner 任务或发起审批 |
| 可信治理机会 | 通过权限、测试、人工确认和发布管理提升可信度 | 上市审批保留人工决策 |

## Exercise 3：选择匹配的实践路径

### Step 1：按目标选择

| 业务目标 | 推荐体验或构建方式 |
|---|---|
| 即时问答、总结、分析和起草 | 智能 Microsoft 365 Copilot 副驾驶®对话助手或应用内 Copilot |
| 复用特定角色、知识、指令和输出方式 | Agent Builder |
| 委托跨文件、多步骤、多成果的完整工作 | Cowork |
| 连接企业数据、工具、动作、渠道与治理 | Microsoft Copilot Studio |
| 数据、权限或业务规则仍需准备 | 先完善条件，再进入原型验证 |

以上方式并非互相替代。应根据业务目标、现有条件和治理要求选择合适的方式，并按需组合。

### Step 2：确定本次原型范围

本工作坊选择 Agent Builder 作为下一步，用于复用以下内容：

- 角色：Launch Program Management Assistant
- 知识：产品概览、里程碑、风险登记和跨部门更新
- 工作方式：分析状态、汇总里程碑、识别风险、生成摘要
- 输出：Launch Readiness Brief
- 人工确认点：资料冲突、风险变更、上市审批和对外发布
